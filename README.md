# 工作助手

客户 × 任务双视角的工作管理工具，装在手机桌面上用。**数据只保存在你自己的手机浏览器里，不经过任何服务器。**

## 这是什么

两个集合、双向关联：

| | **客户集** | **任务集** |
|---|---|---|
| 属性 | 层级（金种子/top360/top1000/top1500/NDKA+）、渠道（FD/体验店/两者）、星级 | 星级、截止日期 |
| 视角 | 客户列表 → 每个客户要落实哪些任务 | 任务列表 → 每个任务在哪些客户落地 |

一条「任务」挂在多个客户身上，**按客户逐家勾选**；所有客户勾完，任务自动完成。也可以一键把整个任务勾掉，所有关联客户一并完成。

完整使用说明见 [`使用说明.md`](./使用说明.md)。

## 功能

- **客户视角**：按层级分组（金种子 → top360 → top1000 → top1500 → NDKA+），同层级内按星级排序；右侧显示未完成/总任务数；点进去看客户信息 + 关联任务，可直接勾选
- **任务视角**：未完成/已完成两页；未完成按截止日期排（最紧迫在最上，无截止沉底），同档按星级；右侧显示未完成/总客户数；点进去看任务信息 + 关联客户逐家勾选
- **客户多选**：任务编辑面板里勾选客户，支持一键全选/清空；客户详情页也能反向关联已有任务
- **数据安全**：本地存储 + 每日自动快照（保留 3 份）+ 导出/导入 JSON 备份 + 删除 6 秒可撤销 + 损坏数据保留不覆盖
- **离线可用**：Service Worker 缓存应用外壳，断网也能打开
- **可安装**：符合 PWA 规范，可添加到手机主屏幕

## 部署

纯静态站点，无构建步骤。把本目录所有文件传到仓库根目录，在仓库 Settings → Pages 里指向根目录即可。

```
index.html            整个应用（HTML + CSS + JS 单文件）
sw.js                 Service Worker，离线缓存
manifest.json         PWA 清单
icon-192.png          图标
icon-512.png          图标
apple-touch-icon.png  iOS 主屏图标
使用说明.md            用户文档
```

本地预览（含手机同局域网访问）：

```bash
node ../serve-work.js     # 端口 8089，手机访问提示的局域网地址
```

直接双击 `index.html` 用 `file://` 打开也能用，只是 Service Worker 不会注册（离线能力失效）。

## 更新时注意

改了 `index.html` 等内容后，**必须把 `sw.js` 里的 `VERSION` 编号加一**，否则老用户会被 Service Worker 的缓存挡住，看到的还是旧版本。

因为策略是「缓存优先」，更新后用户**第一次打开仍是旧版**（后台在悄悄拉新版），**刷新第二次才会看到新版**——这是预期行为。

## 数据存在哪

全部存在浏览器 `localStorage`（键 `work.assistant.v1`），与「佳木待办」（`dsh.todo.v2`）完全隔离、互不影响。换手机、清理浏览器数据、卸载 PWA 都会导致数据消失，**建议定期用「⋯ → 导出备份」存一份**。
