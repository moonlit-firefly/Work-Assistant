# 工作助手

客户 × 任务 × 业务三线并行的销售工作台，装在手机桌面上用。**数据只保存在你自己的手机浏览器里，不经过任何服务器。**

**在线使用**：https://moonlit-firefly.github.io/Work-Assistant/

---

## 一、三个页面

| 页面 | 分工 |
|---|---|
| **周度**（默认页） | 这一周要干什么：提单任务、任务、业务映射，带周历 |
| **业务** | 拜访 / 政企 / 新兴 / 优品机四类业务的客户与月度数据，带月历 |
| **客户** | 客户总表：名称、层级、渠道、星级、备注 |

底部三个标签随时切换。

### 客户页

- **排序：星级优先**——星级高的永远在上面，同星级按层级（金种子 → top368 → top1000 → top1500 → NDKA+ → 破格商 → tier8），再按创建时间。
- 每行右侧显示：未完成任务数 / 关联任务总数。
- 新建 / 编辑：名称、层级（7 档）、渠道（FD / 体验店 / 都选）、星级（1~5）、**月度拜访目标**（留空按层级默认）、备注。
- 点客户进入详情：修改信息、查看关联任务并逐个勾选、右上角 `＋` 关联已有任务。

### 周度页

- **提单任务**固定第一位，右侧显示本周未完成提单的客户数。点进去是本周提单清单：
  - **默认把客户页的全部客户放进来，之后新建的客户也会自动加入**；
  - 点**左边圆圈** = 该客户整体完成（手机 + 融合一起勾上）；
  - 也可以分别点「手机」「融合」两个小标记，**两个都勾即完成**；
  - `×` 把客户从本周清单移除——**不影响客户页**，且不会自动回来；右上角 `＋` 可手动加回。
- **任务**：右上角 `＋` 添加（名称、星级、截止日期精确到分钟、关联客户支持一键全选）。**没做完会一直留着**：W42 没完成的任务，到 W43 还是未完成，直到勾掉为止。
- **任务三页切换**（「本周任务」右侧）：**规划**（全部任务）/ **未完成**（默认）/ **已完成**（显示完成时间）。历史周也能这样看。
- **任务排序：星级优先**——星级高的在上，同星级按截止时间（越近越靠前，无截止沉底），再按创建时间。
- **业务映射**：`＋` 选一个业务（拜访 / 政企 / 新兴 / 优品机），可以**写一段本周规划**（显示在映射右侧，点文字可改）。映射只是「本周这件事要做」：**勾选完成不会改动业务数据**；点它会跳到对应业务页，在那里登记。
- 顶部周条显示本周「**未完成 / 总数**」（任务 + 业务映射一起算），随内容滚动。
- **周历**（右上角 📅）：最近几周 + 下一周。**历史周可修改补录**（规划 / 完成、提单清单都能改）；没有记录的周不会显示其他周创建的数据；**下一周可以进去提前规划**。

### 业务页

四张业务卡，卡片上直接显示本周期的关键数字。右上角 📅 = **月历**（近 6 个月），历史月份**也可以修改补录**——新增记录时把时间改成对应月份即可。二级页面右下角有半透明返回浮窗。

**1. 拜访业务**
- 客户列表就是客户页的客户，右侧「本月 N / 目标 M」。
- 默认目标：**金种子 / top368 每月 6 次，top1000 4 次，top1500 / NDKA+ / 破格商 2 次，tier8 1 次**。
- **改月度目标有两个入口**：① 点客户进拜访详情 → 点「月度拜访目标」那一行直接改（可一键恢复层级默认）；② 客户编辑里的「月度拜访目标」（留空 = 按层级默认）。
- 行内 `＋` 现场登记一次拜访 + 写拜访报告；点客户查看 / 修改过往报告。

**2. 政企业务**
- 创建政企客户：联系人、联系电话、地址、是否开户、是否维系、星级。
- 客户行右侧：**鸿蒙电脑提单数（月度 / 累计）**；`＋` 直接记一次拜访。
- 页头显示：**维系客户数 / 开户客户数**。
- 客户详情：改信息、记鸿蒙提单（按条记录，自动算月度 / 累计）、查看 / 修改拜访记录。

**3. 新兴业务**
- 在政企基础上多一个**提单金额（月度 / 累计）**。
- 页头显示：维系 / 开户、**本月拜访次数**。
- 规则：**每月需要 4 次拜访，且不能挤在两周内完成**——4 次以上挤在 14 天内，页面顶部出黄色提示。
- 客户详情：改信息、记提单金额、查看 / 修改拜访记录。

**4. 优品机业务**
- 创建优品机客户：**月度提单数量、月度提单金额**（按月分桶记录，历史月份保留可查）。
- 客户列表**可拖动排序**：按住行首 `☰` 上下拖。
- 内置「**回收项目**」（固定首位）：`＋` 新增回收记录——回收客户（可从优品机客户里选，也可直接输入）、回收型号、回收数量；右侧显示本月总回收数量。
- 页头显示：**本月总回收数量 / 提单数量 / 提单金额**。

### 更多（⋯）

- **使用指南**：应用内随时查看要点。
- **待办助手**：跳转「佳木的待办」（新页面，两套数据互不影响）。
- **导出 / 导入备份、从自动快照恢复**。

## 二、数据：只在你手机里

- 全部存在浏览器 localStorage（键 `work.assistant.v1`，数据结构 v3，老版本自动迁移）。**完全不上传**，飞行模式也能用。与「佳木待办」完全隔离。
- 保护机制：每日自动快照（保留 3 份）、删除 6 秒可撤销、损坏数据保留原文、导入 / 恢复前自动先存一份。
- **建议每周导一次备份**：清理浏览器数据、卸载应用、换手机都会丢数据。
- 换手机：导出 JSON → 新设备打开同一网址 → 导入备份。不支持自动同步。

## 三、装到手机 / 更新

1. 手机浏览器打开 https://moonlit-firefly.github.io/Work-Assistant/ → 菜单 → **添加到主屏幕**。
2. 验证：开飞行模式能打开 = 离线缓存生效；新建几条重开还在 = 本地存储正常。
3. 更新后第一次打开可能还是旧版，**关掉再开一次**就是新版（缓存策略的预期行为）。

## 四、常见问题

**Q：任务为什么在好几周都出现？**
A：未完成的任务会一直跟着你，直到完成——这是「跨周保留」，不是重复。

**Q：业务数据月底会清零吗？**
A：不会删除任何记录。页面按月归集，切到新月自动只看新月份的数字；旧数据用月历回看。

**Q：历史月份 / 历史周能补记录吗？**
A：能。历史周和历史月都可以修改补录——新增记录时把时间改成对应月份/那周即可；提单、拜访、回收都支持。

**Q：老的历史数据去哪了？**
A：v4 起做了一次清理：周记录只保留上一周开始，月记录只保留上月开始（比如 10 月升级则 8 月及以前的记录已删除）。需要更早的数据用备份 JSON 找回。

**Q：拜访次数的规则会强制拦截吗？**
A：不会。新兴业务的「两周内集中」只提示不拦截——工具提醒你，判断在你。

**Q：提单清单里的客户什么时候自动加进来？**
A：本周清单会在你每次打开时自动补上「客户页有、但清单里还没有」的客户；手动 `×` 移除的不会自动回来。

## 五、部署（开发者）

纯静态站点，无构建步骤。把本目录所有文件传到仓库根目录，仓库 Settings → Pages 指向根目录即可。

```
index.html            整个应用（HTML + CSS + JS 单文件）
sw.js                 Service Worker，离线缓存
manifest.json         PWA 清单
icon-192.png / icon-512.png / apple-touch-icon.png
```

本地预览（含手机同局域网访问）：

```bash
node ../serve-work.js     # 端口 8089，手机访问提示的局域网地址
```

开发辅助脚本（在上一级目录，**不需要上传**）：`make-icons.js`（无依赖 PNG 图标生成）、`make-probe.js`（带演示数据的截图探针页）。

## 更新时注意

改了 `index.html` 后，**必须把 `sw.js` 里的 `VERSION` 加一**（当前 `work-assistant-v5`），否则老用户被缓存挡住看不到新版。更新后用户第一次打开仍是旧版、第二次才见新版——这是缓存策略的预期行为。

## v5 更新要点

- 周度页任务区新增**规划 / 未完成 / 已完成**三页切换，默认停在「未完成」，已完成页显示完成时间。
- 任务排序改为**星级优先**（原为截止优先）。
- 拜访业务的客户详情页可直接改**月度拜访目标**（含恢复层级默认）。
- 新建客户 / 新建任务等弹层间距收紧，**取消 / 创建按钮吸底**，一屏内就能点到。
