# 工作助手

客户 × 任务 × 业务三线并行的销售工作台，装在手机桌面上用。**数据只保存在你自己的手机浏览器里，不经过任何服务器。**

## 三个页面

| 页面 | 管什么 |
|---|---|
| **周度**（默认） | 这一周要干什么：提单任务、任务、业务映射，带周历（历史周可查「规划 / 完成」，下一周可提前规划） |
| **业务** | 拜访 / 政企 / 新兴 / 优品机四类业务，全部按月刷新、按月留存，带月历查历史月份 |
| **客户** | 客户总表：层级（金种子 → top368 → top1000 → top1500 → NDKA+ → 破格商 → tier8）+ 渠道 + 星级；**星级优先排序** |

## 业务一览

- **拜访业务**：客户列表即客户页客户，右侧「本月 N / 目标 M」。默认目标：金种子/top368 每月 6 次，top1000 4 次，top1500/NDKA+/破格商 2 次，tier8 1 次，可逐客户修改。`＋` 现场登记拜访 + 拜访报告。
- **政企业务**：联系人 / 电话 / 地址 / 开户 / 维系 / 星级；鸿蒙电脑提单数（月度/累计）；`＋` 记拜访。
- **新兴业务**：在政企基础上加提单金额（月度/累计）；每月需 4 次拜访且**不能挤在两周内**（挤在一起页面会提示）。
- **优品机业务**：月度提单数量 / 金额（按月分桶记录，历史保留）；客户可按住 `☰` 拖动排序；内置「回收项目」记录回收客户 / 型号 / 数量。

任务未做完会自动留在下一周，直到完成；业务映射只是「本周这件事要做」的提醒，勾选不改业务数据。

完整使用说明见 [`使用说明.md`](./使用说明.md)。

## 部署

纯静态站点，无构建步骤。把本目录所有文件传到仓库根目录，在仓库 Settings → Pages 里指向根目录即可。

```
index.html            整个应用（HTML + CSS + JS 单文件）
sw.js                 Service Worker，离线缓存
manifest.json         PWA 清单
icon-192.png / icon-512.png / apple-touch-icon.png
使用说明.md            用户文档
```

本地预览（含手机同局域网访问）：

```bash
node ../serve-work.js     # 端口 8089，手机访问提示的局域网地址
```

开发辅助脚本（在上一级目录，**不需要上传**）：`make-icons.js`（无依赖 PNG 图标生成）、`make-probe.js`（带演示数据的截图探针页）。

## 更新时注意

改了 `index.html` 后，**必须把 `sw.js` 里的 `VERSION` 加一**（当前 `work-assistant-v2`），否则老用户被缓存挡住看不到新版。更新后第一次打开仍是旧版、第二次才见新版——这是缓存策略的预期行为。

## 数据存在哪

全部在浏览器 `localStorage`（键 `work.assistant.v1`，数据结构 version 3，老版本自动迁移）。换手机、清理浏览器数据、卸载 PWA 都会导致数据消失，**建议每周用「⋯ → 导出备份」存一份**。与「佳木待办」完全隔离、互不影响。
